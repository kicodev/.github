<h3 align="center">Say what you need. Kico builds it, checks it and keeps it running.</h3>

Kico is an AI app builder for teams, made by Unifying Systems LLC in Austin, Texas.

- **Apps.** One line in the chat starts a project. A dev agent builds it in its own Debian sandbox, on any stack (Vite, Next.js, Django, FastAPI, PHP or a plain script), and checks it in a headless browser before it says done. Import from GitHub or any Git server, push back to GitHub, download a zip.
- **An assistant per person.** It knows your projects and colleagues, keeps a memory you can read and edit, and runs on schedules and events.
- **Agents with their own email.** Each agent has one job, its own tools, its own model and an address like `invoices.<you>@agents.kico.dev`. What it would send because of an event or a mail waits for your approval.
- **Your models.** Anthropic, OpenAI, Google Gemini, OpenRouter, xAI, NVIDIA and Reflection AI with your own key or plan, or open-weight models on your own GPU through vLLM, LM Studio, ollama or llama.cpp.
- **Your data, read-only.** PostgreSQL, MySQL and MariaDB, SQL Server, Oracle and SQLite. Passwords never reach a sandbox, and every query is logged.

### Kico for WordPress

A plugin that connects a self-hosted WordPress site to Kico. Your assistant, agents and dev agents can then change posts, pages, Elementor layouts, plugins, themes, files and the database, and run WP-CLI.

- Every write is snapshotted outside the site and can be rolled back. A rollback can be undone too.
- Writes that a mail or an event started wait for your approval.
- Updates install only when the release is signed with a key pinned in the plugin.
- Requires WordPress 6.9+ and PHP 7.4+. Licensed GPLv2 or later.

[Download the plugin](https://kico.dev/download#wordpress) · [Source](https://github.com/kicodev/kico-for-wordpress) · [What it does](https://kico.dev/wordpress) · [Troubleshooting](https://kico.dev/help/wordpress)
